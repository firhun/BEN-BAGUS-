💾 Backup & pindah data

Simpan semua data (transaksi, minuman, pengeluaran, pengaturan) ke satu file. Berguna untuk cadangan, atau memindahkan data ke perangkat lain (mis. dari iPad ke komputer).

⚠️ Import akan mengganti seluruh data yang ada sekarang dengan isi file. Pastikan sudah backup dulu kalau ragu.

🗑️ Reset data

Hapus semua riwayat transaksi & pengeluaran (daftar layanan, minuman, tukang cukur tetap ada).

☁️ Sinkron data via GitHub

Simpan data ke repo GitHub pribadimu supaya bisa diakses & sinkron antar perangkat (iPad ↔ komputer). Isi sekali di tiap perangkat. Token disimpan di perangkat ini saja, tidak dibagikan.

Token disimpan lokal di perangkat ini. Jangan pakai di perangkat milik orang lain.

ℹ️ Cara pakai singkat

  1. Buat repo private di GitHub (cth: data-barber).
  2. Buat Personal Access Token (fine-grained) dengan izin Contents: Read & write untuk repo itu.
  3. Isi username, nama repo, dan token di atas, lalu Simpan pengaturan & Tes koneksi.
  4. Di perangkat pertama: tekan Kirim data ke GitHub.
  5. Di perangkat kedua: isi pengaturan yang sama, lalu tekan Ambil data dari GitHub.
  6. Karena cuma 1 orang gantian perangkat: biasakan Ambil saat mulai, dan Kirim saat selesai (atau nyalakan otomatis kirim).
